Aamir Mohammed Khan built small browser games including a two-player memory-card game and a 2D platformer prototype, using JavaScript, browser Canvas, and custom visual assets. Both games were made completely by Aamir as solo projects.

These are creative coding exercises that explore interactive logic, game-state handling, movement, collision behaviour, camera tracking, visual assets, and user feedback such as sounds and retry controls. The browser game uses a client-side state/update/render loop: game state tracks the player, platforms/cards, camera, and interaction state; input handlers translate keyboard or pointer events into actions; rendering draws the scene and UI; collision and game-state logic update the world.

Design highlights include Canvas rendering for control over 2D visuals and animation, camera/parallax effects for depth and movement, and custom assets and sound for feedback and identity.
