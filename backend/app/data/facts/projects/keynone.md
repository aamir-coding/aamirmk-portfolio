Keynone is a local, private voice-dictation application for Windows built by Aamir Mohammed Khan as an open-source personal project. It converts speech to text in the active application, removes filler words and repetitions, applies self-corrections, formats punctuation and lists, and types the result wherever the cursor is.

Keynone runs locally on the CPU using open models. All audio and text processing stays on the user's computer rather than being sent to a cloud service, prioritising privacy and offline capability.
