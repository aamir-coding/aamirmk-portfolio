### 1. Offline implementation

No remaining production defect requires reopening the whole retrospective before building an offline evaluation harness. Approval of this brief and disposition of remediation close-out are the workflow gates. The following evaluation-integrity gaps belong inside Phase 8 and must be resolved before accepting its offline results:

- Define reviewed labels, metric denominators, case versions and a frozen held-out split. The existing 45 retrieval questions and four curated fit assessments are development material, not a new blind set or calibrated ground truth.
- Fingerprint actual corpus content, embedding inputs/model and index artifact; reject stale or unproven combinations. Hashing an already-stale matrix does not establish freshness. Existing `.npz` keys are only `ids` and `matrix`.
- Isolate runs from seeded/stale fit caches and mutable cross-run dependencies. Record answer origin explicitly; a cached preset is not a fresh model answer. Use the real production pipeline logic with injected dependencies, not a second implementation.
- Separate citation identity/local membership checks from semantic support. Add unrelated, negative and absent evidence cases, including summary/ramp-up claims. Offline replay can measure known examples without certifying the live model.
- Add real event-contract fixtures, request telemetry and root eval/gzip CI gates. Replay tests the checker and recorded outputs; it cannot prove that a changed generator prompt still produces those outputs.
